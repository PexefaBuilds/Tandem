# Security policy

Tandem handles sign-in cookies and tokens for your Claude and Codex accounts, so security reports matter a lot.

**Please don't open public issues for security problems.** Email **[security contact email]** instead, with steps to reproduce. You'll get a reply within 7 days.

What we promise:
- Secrets never leave your machine, except in requests to the service they belong to (`claude.ai`, `chatgpt.com`).
- Secrets are never logged or written into crash reports.
- Releases are built by GitHub Actions from tagged commits.
